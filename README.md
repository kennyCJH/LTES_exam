# 嘉義市蘭潭國小 考試倒數計時時鐘系統

專為**嘉義市蘭潭國小（LTES）**量身打造的互動式考場時鐘，支援全螢幕投影、智慧自動跳轉倒數、擬真校園鐘聲、校徽展示，以及**自訂學年度/學期/考查名稱**與**考試日程/節次範圍線上編輯與範例檔匯入匯出**功能。

---

## 🌟 新增功能與升級重點

### 1. 學年度、學期別與考查名稱完全可自訂
- 頂部標題：「**115 學年度 上學期 第一次定期考查 考試倒數計時時鐘**」
- **直覺快速修改**：直接在網頁頂部點擊該列（或點擊 ✏️ 鉛筆圖示），即可彈出編輯對話框：
  - **學年度**：可直接按 `-1`、`+1` 或輸入任意數字（例如 115、116、117...）
  - **學期別**：可選擇「上學期」或「下學期」
  - **考查次別**：可選擇「第一次定期考查」、「第二次定期考查」、「期中定期評量」、「期末定期評量」、「畢業考查」或「自訂名稱」
  - 修改後立即同步更新畫面頂部與瀏覽器分頁標題，並自動存入瀏覽器儲存空間（LocalStorage）。

### 2. 蘭潭國小專屬官方校徽圖案
- 左上角已更換為學校官方上傳的**彩色蘭潭校徽圖檔**（`lantan_logo.png`），圓角優雅呈現。
- **支援自訂更換**：進入「⚙️ 設定」可上傳更換其他活動圖片或新校徽，並隨時有一鍵「還原預設校徽」按鈕。

### 3. 考試日期與考試節次可編輯、範例檔下載與上傳更新
點擊頂部功能列的「**📅 考程管理**」按鈕：
- **📥 下載考程範例檔 (JSON)**：
  - 一鍵下載標準範例檔（如 [`蘭潭國小_考程範例檔.json`](file:///c:/Users/USER/Documents/LTES_exam/蘭潭國小_考程範例檔.json)），包含各年級、各節次、科目與完整範圍結構。
- **📤 上傳考程更新檔**：
  - 教務處或老師編輯好 JSON 檔案後，直接點擊上傳，系統自動校驗並瞬間套用至全校所有年級！
- **✏️ 線上視覺化表格編輯**：
  - 可直接在瀏覽器彈窗中：
    - 切換管理不同考試日期（可「➕ 新增考試日期」或「🗑️ 刪除此日期」）
    - 切換不同年級（1~6年級）
    - 在表格內直接修改：節次序號、節次名稱、考試科目、考試範圍
    - 點選「➕ 新增考試節次」或「🗑️ 刪除列」
    - 點擊「儲存並立即套用考程」，全系統即時生效！
- **🔄 還原蘭潭預設課表**：
  - 隨時可一鍵還原為 115 學年度第一次定期考查的官方原始課表。

### 4. 五大視覺主題切換（新增「🌌 宇宙天文」風格）
- 🌲 **蘭潭校園**（湖光翠綠清新）
- 🌌 **宇宙天文**（蘭潭星象深邃藍，星軌星雲科技感）
- 🌙 **考場投影專用**（深色超高對比，投影清晰不刺眼）
- 🍂 **護眼暖色**（琥珀專注金）
- 🎓 **黑板粉筆風**（復古墨綠教室感）
